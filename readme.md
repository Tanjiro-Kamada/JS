1.for loop -> is used when the no of iterations is known before hand -> uses the for keyword syntax

for( initialization; condition ; update ){
    //block of code to be executed repeatedly
}
initialization -> the starting point of a loop e.g loop from 1 to 1000 -> initialization is 1 condition -> this is what keeps the loop running -> as long as the condition is met , the loop keeps running -> when the condition is no longer met, the loop breaks update -> increment / decrement after each iteration (++ / --)
